ATTENTION: mods for LEGACY version (gen8) will cause crash on ENHANCED version (gen9) (tips: post 2025)

1. Script Hook V + Native Trainer
https://www.gta5-mods.com/tools/script-hook-v
put .asi & .dll files from 'bin' folder to game folder (except dinput8.dll)

Native Trainer Controls
F4 - activate
NUM2/8/4/6 - navigate thru the menus and lists (numlock must be on)
NUM5 - select
NUM0/BACKSPACE/F4 - back
NUM9/3 - use vehicle boost when active
NUM+ - use vehicle rockets when active
